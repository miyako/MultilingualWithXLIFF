**目的**

XLIFF（XML Localization Interchange File Format）を使って4Dアプリケーションの
表示言語を切り替えるデモです。

**起動**

Project/LangageSwitching.4DProjectを4Dで開きます。元の案内では4D 20.4または
20 R5を使用します。プロジェクトの互換性バージョン19 R8は変更していません。

起動時は日本語の操作ガイドを表示します。「デモ」をクリックすると、
言語切り替えの説明と操作画面に進みます。メニューから再度開始すると、
既存のガイドまたは操作画面を前面に表示します。

**操作**

- 「デモ」タブで言語を選び、「選択した言語で開く」をクリックします。
  ダイアログを閉じると、日本語の操作画面に戻ります。
- 「全言語を別プロセスで開く」で英語、スペイン語、フランス語、ドイツ語、
  イタリア語、日本語のダイアログを開きます。
- 数、曜日、月名、ボタンなどの既存の多言語サンプルはそのままです。
  日本語の月名には睦月、如月などの旧称を使用します。
- 「この言語での1月の名前」で、そのウィンドウの言語の月名を表示します。
- Webエリアは対応する言語の4Dサイトを表示します。インターネット接続が必要です。
- 「アラビア語を読み込む」でResources/ExcelArabic1.txtを読み込みます。
  元ファイルはBOM付きUTF-16LEです。バイト列をTable_1のChamp_2に保存し、
  UTF-16でデコードした内容を画面に表示します。読み込みごとにレコードを作成する
  元の動作は維持しています。元のアラビア語テキストと国データは変更していません。

**翻訳リソース**

Resources/<言語>.lproj/内のXLIFF 1.2ファイルを使用します。
SamplesXX.xlfは既存のサンプル値、LangageSwitchingXX.xlfは画面・メッセージ、
CommonHDIXX.xlfは既存の共通メニュー用文字列です。XXはEN、JAなどの言語接尾辞です。
日本語と英語のUIを整備し、他の4言語には未翻訳の画面用文字列を英語で明示的に補っています。
それらはXLIFFでneeds-translationとして記録しています。

**技術ノートとの違い**

本文・図中のプログラムコードは原文を維持しています。デモ側では、起動を
ノンブロッキングにし、実ファイルに合わせてUTF-16で読み込むように修正しました。
また、説明画面にあったSET DATABASE LOCALIZATIONの*による適用範囲の逆転を修正しました。
*なしはデータベースとコンポーネント、*ありは呼び出し元のデータベースのみです。

**検証**

リポジトリのルートでpython tools/test_demo.pyを実行すると、
翻訳リソース、参照先、フォームのメソッド結合、元サンプルの保持を確認できます。
TOOL4Dにtool4d実行ファイルのパスを設定すると、一時コピーで全言語の文字列解決、
新規データファイルへのアラビア語読み込み、およびプロジェクト全体のコンパイルも行います。
既存のData/は使いません。

Data/、Settings/、Logs/、Project/DerivedData/はローカルの実行用ファイルで、
配布物やバージョン管理には含めません。既存のデータファイルは上書きしません。
